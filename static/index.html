AOT-GOAT

Same message, different recipient histories: score the risk of being misread, decide whether to intervene, and make the smallest edit that fixes it.

Sender context (JSON)

Facts the sender supplies: pronoun referents, glossary, context notes, reference date. Edits may only use these, the history, and the message itself.

Recipients

One line per message, starting with S: (sender) or R: (recipient).

Pick a scenario and run the analysis. Results for each recipient appear here.

Deterministic offline analyzer; takes about a second.
Demo data and evaluation cases are synthetic and hand-written. Offline mode uses a rule-based analyzer, not an LLM. Nothing here is real-world evidence.
